Настройка камер и сети

Перед развертыванием системы видеонаблюдения на базе «iDLook», необходимо произвести монтажные работы (прокладку кабелей для Ethernet сети (при необходимости), настройка и крепление камер видеонаблюдения). Обычно сеть должна содержит в себе подключаемые видеоустройства (IP-камеры, видеорегистраторы), необходимые компьютеры, PoE коммутатор (ы) для камер и маршрутизатор для удаленного доступа. Маршрутизатор для удаленного доступа, обязательно должен поддерживать перенаправление портов: порты 80, 554, 8000 входящего подключения, должны быть перенаправлены на аналогичные порты локального IP адреса компьютера, с установленным ПО «iDLook». Кроме того, при использовании удаленного доступа клиентов через Интернет, необходимо использовать фиксированный Web IP адрес, в сети провайдера.

Настройку IP камер удобно с помощью браузера: после авторизации на странице настройки камеры, можно произвести необходимые настройки видеопотоков камеры. При подключении камер «из коробки» на них может быть установлены высокие битрейт и разрешение или выбран неподдерживаемый кодек. Рекомендуется производить настройку камер последовательно, с контролем загруженности ресурсов ПК (CPU/GPU/Memory/Ethernet/Disk), используя программу контроля ресурсов (в Windows - «Диспетчер задач» или аналогичное ПО) и форму «Информация» ПО «iDLook».
