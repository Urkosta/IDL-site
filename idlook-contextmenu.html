Всплывающее меню

Помимо главного меню, в программе используется и всплывающее контекстное меню. Это меню появляется при клике правой клавишей мыши на окно любой отображаемой камеры.

В этом меню можно:

  • открыть форму для работы с архивом выбранной камеры;
  • открыть форму для работы с сохраненными фрагментами выбранной камеры;
  • открыть устройство на форме Камеры, для изменения настроек подключенной камеры;
  • сделать моментальный снимок из видеопотока (текущий кадр);
  • распечатать моментальный снимок на принтере по умолчанию.
